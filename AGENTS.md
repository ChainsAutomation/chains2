# Repository instructions

- Update documentation in the same change whenever significant work warrants new documentation or makes existing documentation inaccurate. Review the relevant README sections and guides in `docs/`, and update affected examples, commands, and configuration references.
- Write an architecture decision record (ADR) in `docs/adr/` in the same change whenever you make a significant architectural or system design decision. Use the next available number and record the context, decision, alternatives considered, and consequences.
